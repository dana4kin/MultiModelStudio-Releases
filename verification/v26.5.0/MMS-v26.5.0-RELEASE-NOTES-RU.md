# MultiModelStudio 26.5.0

Выпуск добавляет мультимедийный чат и управляемое Computer Use с проверкой фактических возможностей выбранной связки модель–runtime–устройство.

## Мультимедиа

- Добавлен отдельный provider генерации изображений через совместимый `sd-server`.
- Чат отображает загруженные и сгенерированные изображения, видео и аудио.
- История и экспорт сохраняют мультимедийные блоки и рассуждения в предусмотренных форматах.
- Формат модели и возможность runtime проверяются до выдачи функции агенту.

## Computer Use и навыки

- Добавлены управляемые драйверы дисплея, мыши, клавиатуры, браузера и рабочего стола.
- Разрешения и побочные эффекты проходят через общую политику инструментов MMS.
- В поставку включены закреплённые официальные CLI `agent-desktop 1.3.0` и `agent-browser 0.43.0` для соответствующей ОС и архитектуры. MMS проверяет их SHA-256 перед запуском.
- Chrome for Testing не включён. До его отдельной установки browser automation показывает точную недостающую зависимость и остаётся недоступной.
- Добавлены встроенные навыки Computer Use, браузерной автоматизации, проверки интерфейса, технического письма и декларативного UI.
