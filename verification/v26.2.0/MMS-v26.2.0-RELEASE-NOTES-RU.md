# MultiModelStudio 26.2.0

Выпуск объединяет ONNX Runtime GenAI с актуальным интерфейсом, восстанавливает потерянные
контракты команд и рабочих поверхностей и обновляет автономную встроенную справку.

## Основные изменения

- **ONNX Runtime GenAI:** провайдер включён в общую архитектуру runtime и новый интерфейс.
  Поддерживаются управляемые профили Windows CPU и DirectML, диагностика, жизненный цикл,
  идентификация развёртывания и проверка возможностей. Отдельные правила параметров генерации
  не вводились: используются общие настройки агента и модели.
- **Восстановленные контракты:** справка CLI снова показывает действующие команды работы
  с артефактами; справка HTTP-сервера перечисляет операции обычной и объектной памяти.
- **Полнота решения:** пять проектов, использовавшихся прямыми зависимостями, включены в
  основное решение. Новый архитектурный тест блокирует повторную потерю таких проектов.
- **Рабочие поверхности:** в общий каталог добавлены независимая оценка знаний и внутренний
  комплект проверки провайдеров.
- **Справка:** 48 разделов, 36 автономных снимков интерфейса и воспроизводимый каталог
  433 команд, связанных с 664 элементами Avalonia/WPF. Поиск и изображения работают без сети.

## Возможности программы

- проекты, рабочие области, отдельные агенты, история, черновики и проектные права;
- один или два чата, несколько участников, потоковые ответы, вложения, поиск и экспорт;
- локальные и удалённые модели через GGUF, llama.cpp, MOTEKA, vLLM, ONNX Runtime GenAI
  и OpenAI-совместимые API;
- настройки агентов, контекст, параметры ответа, память, документы, навыки и права;
- память с ревизиями, доверием, откатом и связями, объектная память и базы знаний;
- инструменты и MCP с подтверждениями, лимитами, stdio/HTTP, ресурсами и задачами;
- расписания, мультиагентные планы, федерация, сеть и зеркала чатов;
- материалы для обучения, LoRA/QLoRA, CPU/CUDA, оценка, пробный чат, активация и откат;
- переносимые артефакты, backend-модули, аудит, диагностика и безопасный support bundle.

## Установка

**Windows:** запустите Setup. Для переносимой копии используйте
`MMS-v26.2.0-Setup.exe --portable <новая-папка>`.

**Linux:** распакуйте архив и выполните `./Start-MMS.sh`.

**macOS:** распакуйте архив, сначала запустите `FIRST_RUN.command`, затем
`MultiModelStudio.app`. Архивы сохраняют права запуска.
