# MultiModelStudio — релизы и справка

Официальный публичный репозиторий готовых сборок и пользовательской документации **MultiModelStudio**.

## Скачать

Актуальный выпуск: **[MultiModelStudio 26.1.0](https://github.com/dana4kin/MultiModelStudio-Releases/releases/tag/v26.1.0)**.

Доступны автономные пакеты для:

- Windows x64 — установщик и переносимый ZIP;
- Linux x64;
- macOS Apple Silicon;
- macOS Intel.

Среда .NET включена в каждый пакет. Модели, внешние runtime, MCP-серверы и пользовательские данные в поставку не входят.

## Справка

- **[Открыть веб-справку](https://dana4kin.github.io/MultiModelStudio-Releases/)**
- [Справка в Markdown](docs/CONSOLIDATED_HELP_RU.md)

Руководство содержит 48 разделов, 36 автономных снимков интерфейса и каталог всех 320 команд, связанных с 522 элементами Avalonia/WPF.

## Проверка файлов

Для каждого установочного пакета в GitHub Release опубликован файл `.sha256`. Дополнительные материалы находятся в [`verification/v26.1.0`](verification/v26.1.0):

- публичный ключ RSA;
- подписанный перечень пакетов;
- описание выпуска и контрольная сумма.

## Лицензия

MultiModelStudio является проприетарным программным обеспечением и не становится open-source из-за публичной публикации готовых сборок и справки. Условия использования приведены в [LICENSE.md](LICENSE.md).

Исходный код в этом репозитории не публикуется.
